# Installation

PolySheet installs for your Windows account without administrator access. Choose a dedicated empty folder. Setup offers independent desktop and Start menu shortcut choices and registers .polys as an available file type without changing the default application.

PolySheet has its own installer identity, registry keys, local settings and recovery data. It does not replace PolyPDF or PolyWriter. Close all PolySheet windows before setup/uninstall. Setup preserves previous installation location and shortcut choices and rejects downgrades.

Uninstall from Windows Settings or Uninstall.exe. User documents, preferences and recovery copies are kept. Only owned program files are removed. The portable package can be extracted into a separate folder and runs without installation; in-place application updates require a registered installation.
